# Aakriti Pariyar — Portfolio

A responsive, accessible portfolio built with HTML, CSS, and JavaScript. No build step or API keys required.

## Features

- Animated orbital hero, custom project illustrations, and scroll reveals
- Mobile navigation, active section links, and persistent light/dark themes
- Project filters and keyboard-accessible project dialogs
- Skill tabs with arrow-key, Home, and End navigation
- Email copy button and validated email-draft form (opens an email client; does not send messages)
- Printable professional profile at `profile.html`
- Reduced-motion support and print styles

## Run locally

```sh
python3 -m http.server 8000
```

Open http://localhost:8000.

## Publish with GitHub Pages

In this repository, open **Settings → Pages**. Choose **Deploy from a branch**, select **main** and **/ (root)**, then save. Once GitHub finishes deployment, the site will be available at https://aakritipariyar.github.io/portfolio/.

## Update content

Edit `index.html` for page content and `script.js` for project details. Update `profile.html` when your experience changes. Project artwork is illustrative. The weather notebook and campus prototype source are not currently published, so those cards show honest project summaries without dead demo links.

Google Fonts is optional; local fallback fonts keep the site usable offline. No analytics, backend, or third-party form service is configured.
